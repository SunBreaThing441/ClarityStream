# ClarityStream

A full-stack scholarship management platform designed to help students explore and apply for scholarships, while providing administrators and moderators with tools to manage scholarships, applications, and reviews efficiently.

## Project Structure

- **[scholar_stream-client](./scholar_stream-client)**: Frontend application built with React, Vite, Tailwind CSS, and DaisyUI.
- **[scholar_stream-server](./scholar_stream-server)**: Backend API built with Express, Node.js, and MongoDB.

## Getting Started

### Client
1. Navigate to the client directory:
   ```bash
   cd scholar_stream-client
   npm install
   npm run dev
   ```

### Server
1. Navigate to the server directory:
   ```bash
   cd scholar_stream-server
   npm install
   npm start
   ```
